Step-by-step GAS setup
1Open script.google.com → New Project → paste the contents of clinic-audit-gas.js → Save.
2In the script editor, run setupSheets() once (Resources → Run function) to create the sheets automatically.
3Click Deploy → New deployment → Type: Web app → Execute as: Me → Who has access: Anyone → Deploy.
4Copy the Web App URL provided after deployment and paste it below.
5Click Test Connection. Once connected (green dot), you can start auditing.
